# HTERP-WP-009 — Source Reader / Proto-Canon

**Status:** completed as architecture  
**Version:** 1.0  
**Nature:** provenance-aware reading system, not a closed canon

## Purpose

Create a structured reader for the Provisional Way without:
- copying copyrighted modern translations wholesale;
- pretending every text has equal source proximity;
- harmonizing contradictions;
- cherry-picking only agreeable passages;
- confusing canonical importance with historical certainty.

## Reader architecture

### Section I — Abrahamic Prophetic Spine
1. Torah
2. Hebrew Prophets
3. Jesus Witness Corpus
4. Qur'anic / Muhammad Witness Corpus

### Section II — Parallel High-Value Witnesses
5. Gathas / Zarathustra
6. Guru Nanak / early Sikh bani

### Section III — Comparative Awakening / Wisdom
7. early Buddhist witness
8. selected wisdom/contemplative appendix

## Annotation system

Every reading receives:
- canonical layer;
- source/provenance note;
- original-language terms;
- historical context;
- dependency note;
- TRACE questions;
- contradiction links;
- difficult-text flag where required.

## Critical principle

A proto-canon is not a list of texts declared infallible.

It is a **governed reading corpus**: a body of sources important enough to be read repeatedly, critically, devotionally, and comparatively.

## Anti-cherry-picking rule

Every major source body must maintain a **Difficult Text Register** covering passages that challenge the community's preferred theology or ethics.

## Copyright rule

The project stores:
- citations;
- pericope/chapter maps;
- public-domain/open translation links where suitable;
- original-language key terms;
- short quotations only when legally appropriate.

It does not reproduce entire copyrighted modern translations without permission.
