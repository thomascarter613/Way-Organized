# HTERP-WP-011 — Difficult Text Analysis I

**Status:** completed  
**Version:** 1.2  
**Units:** 12 difficult-text clusters

## Purpose

A credible constructive framework cannot claim “original truth” by retaining only passages it already likes.

Each file therefore states:
- what the source actually permits/commands/imagines;
- historical context;
- strongest charitable interpretation;
- strongest ethical objection;
- later reception;
- constructive decision.

## Constructive decision labels

- **RETAIN** — normative value retained.
- **REINTERPRET** — retained only through an explicitly revised reading.
- **SUSPEND** — no present normative conclusion.
- **REJECT NORMATIVE FORCE** — the text remains in the corpus but the action/rule is not binding and may be morally rejected.

Historical preservation is never erased by normative rejection.
