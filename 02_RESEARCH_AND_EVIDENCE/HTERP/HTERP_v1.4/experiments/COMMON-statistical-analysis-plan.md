# Common Statistical Analysis Plan

## Principle 1 — Effect before explanation
First ask:
> Does performance exceed the preregistered control/chance distribution?

Only afterward ask what could cause it.

## Principle 2 — Exact randomization tests where practical
For matching/ranking designs, permutation tests are preferable because the null distribution follows directly from random assignment.

## Principle 3 — Report effect sizes
A very small statistically significant effect is not the same as a practically strong anomaly.

Report:
- absolute difference from chance/control;
- standardized effect where suitable;
- uncertainty intervals.

## Principle 4 — No optional stopping
Stopping depends on preregistered:
- fixed N;
- or sequential boundary.

Do not stop because results “look significant.”

## Principle 5 — Multiplicity
One primary endpoint.
Secondary endpoints corrected or clearly exploratory.

## Principle 6 — Individual heterogeneity
If only a subset performs:
- subset criterion must be prospective for confirmatory claims;
- exploratory “star performer” findings require new replication.

## Principle 7 — Bayesian analysis may supplement, not hide flexibility
If used:
- priors declared in advance;
- sensitivity reported.

## Principle 8 — Benchmark against human inference
When targets contain ordinary social information, compare against:
- chance;
- lay controls;
- trained inference/cold-reading controls where relevant.

## Principle 9 — Replication
A novel anomalous effect changes HTERP substantially only after independent replication.

## Suggested evidence language
- no evidence beyond control;
- weak/suggestive deviation;
- preregistered anomaly detected;
- independently replicated anomaly;
- source unresolved.

Never jump from p-value to ontology.
