# Common Preregistration Standard

Every HTERP confirmatory experiment must specify before data collection:

## Identity
- protocol version
- investigators
- roles/conflicts
- sites
- sponsor/funding

## Hypotheses
- primary hypothesis
- null/control expectation
- secondary/exploratory hypotheses

## Participants
- inclusion/exclusion
- recruitment
- stopping rule
- target sample size rationale

## Randomization
- method
- seed handling or secure service
- who can access allocations

## Blinding
List exactly who is blind to:
- target;
- condition;
- participant identity;
- scoring key;
- analysis groups.

## Outcomes
- one primary outcome;
- secondary outcomes;
- scoring rubric.

## Exclusions
Defined before unblinding.

## Missing data
Predefined treatment.

## Analysis
- statistical test;
- effect measure;
- uncertainty interval;
- multiplicity correction;
- robustness checks.

## Success threshold
Define what result would:
- count as failed;
- count as suggestive;
- trigger replication;
- count as replicated.

## Interpretation firewall
Specify conclusions the design **cannot** establish even if positive.

## Data
- raw-data plan;
- anonymization;
- code;
- audit trail;
- retention.
