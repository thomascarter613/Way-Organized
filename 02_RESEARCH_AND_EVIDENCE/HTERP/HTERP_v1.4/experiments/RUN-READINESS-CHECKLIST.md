# Experiment Run-Readiness Checklist

Before any EXP-001–004 launch:

- [ ] actual research lead identified
- [ ] institution/ethics pathway identified
- [ ] proponent investigator
- [ ] skeptical investigator
- [ ] neutral methods/statistics lead
- [ ] preregistration drafted
- [ ] sample-size rationale completed
- [ ] secure randomization system
- [ ] privacy/data plan
- [ ] fraud/leakage threat model
- [ ] pilot test with dummy data
- [ ] analysis code tested before unblinding
- [ ] adverse-event plan
- [ ] publication commitment includes null result
- [ ] interpretation-limit statement signed

Until these are complete, the protocol remains a design, not an experiment.
