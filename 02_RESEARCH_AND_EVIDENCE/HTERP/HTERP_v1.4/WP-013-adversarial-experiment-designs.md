# HTERP-WP-013 — Adversarial Experiment Designs

**Status:** protocol suite completed; not yet run  
**Version:** 1.4

## Purpose

Create prospective tests capable of updating HTERP's transcendent/anomalous-information hypotheses.

The protocols do **not** assume:
- mediumship is spirit communication;
- prophecy comes from God;
- channeling is fraud;
- anomalous information is impossible.

They are designed to determine whether information exceeds preregistered normal/control expectations.

## Protocol suite

1. Mediumship multisite adversarial replication
2. Charismatic “word of knowledge” trial
3. Channeling hidden-target trial
4. Prospective prophecy registry
5. Common preregistration standard
6. Common data schema
7. Statistical analysis plan
8. Ethics/safety standard

## Governing inference rule

> **Detect anomaly first. Identify source later.**

Even a positive result does not automatically establish:
- spirits;
- God;
- angels;
- deceased consciousness;
- precognition;
- telepathy.

## Adversarial governance

Every confirmatory test should include:
- a proponent investigator;
- a skeptical investigator;
- an independent methods/statistics lead.

No one faction controls:
- target generation;
- exclusions;
- scoring;
- unblinding;
- interpretation.

## Genuine next boundary

The project cannot honestly advance these protocols from “designed” to “evidence” without:
- human participants;
- ethics/consent review appropriate to setting;
- prospective preregistration;
- data collection.

That is now a real external boundary rather than a missing document.
