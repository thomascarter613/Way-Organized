# Doctrine and Evidence Amendment Process

## Status labels
Every constructive proposition carries one label:
- **R** research conclusion
- **F** faith postulate
- **P** permitted interpretation
- **O** open question
- **D** deprecated/rejected claim

## Evidence update pipeline

new evidence  
→ source validation  
→ HTERP dossier update  
→ hypothesis-ledger update  
→ constructive impact review  
→ public change proposal  
→ reasoned decision  
→ versioned publication.

## Amendment classes

### Class A — editorial
No substantive doctrine change.

### Class B — interpretation
Changes status/confidence without altering public covenant.

### Class C — doctrine
Changes a faith postulate or permitted branch.

### Class D — constitutional
Changes epistemology, ethical covenant, or authority architecture.

Class D requires the highest level of deliberation and cannot be enacted merely by one charismatic leader claiming revelation.

## Emergency safeguard
A new private revelation has **zero automatic constitutional authority**.

It may be recorded as an encounter claim and subjected to HTERP review.

## Versioning principle
Never erase former doctrine silently.
Maintain:
- date;
- prior wording;
- new wording;
- evidence/reason for change.
