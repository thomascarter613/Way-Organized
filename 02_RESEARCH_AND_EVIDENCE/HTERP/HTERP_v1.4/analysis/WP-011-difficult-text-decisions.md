# Difficult Text Decisions — Pass I Summary

| Cluster | Constructive decision |
|---|---|
| slavery | reject human ownership as normative |
| herem/conquest | reject genocide/ethnic cleansing/holy-war imitation |
| Akedah | reinterpret; prohibit child-harm obedience model |
| plagues/firstborn | suspend moral vindication; reject imitation |
| apocalyptic violence | reinterpret and constrain |
| Gehenna | retain accountability; suspend detailed hell metaphysics |
| Jesus exclusivity | suspend final exclusivist metaphysics |
| Qur'anic warfare | contextualize; reject coercive/offensive religion-based violence |
| Q 4:34 | reject spouse violence/coercive hierarchy |
| pluralism/exclusivity | retain truth-disagreement + freedom of conscience |
| apostasy | reject punishment for mere belief-change |
| Buddhist karma/gender | retain intention/compassion; reject hierarchy/victim-blaming |

## Methodological result

Historical context may explain why a text says what it says.

It does **not** automatically convert a morally troubling ancient norm into a binding modern command.

The Provisional Way therefore allows:
> foundational text + critical preservation + explicit normative rejection

without deleting the text from the corpus.
