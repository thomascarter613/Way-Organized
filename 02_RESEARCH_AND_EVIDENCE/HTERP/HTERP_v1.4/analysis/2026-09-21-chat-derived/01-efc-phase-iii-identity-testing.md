# EFC Phase III — Expectation Convergence and Identity Testing

## Question

Could different traditions actually refer to the same expected figure under different titles?

Functional similarity is insufficient. Identity testing requires referent continuity, textual genealogy, biography, temporal mechanism, ontology, mission, revelation/law relation, and contradictions.

## Identity classes

| Class | Meaning |
|---|---|
| I-5 | Same historical referent |
| I-4 | Explicit reidentification of an inherited role |
| I-3 | Genealogically related role, individual identity disputed |
| I-2 | Possible influence/convergence, identity unsupported |
| I-1 | Structural analogy |
| I-0 | Material incompatibility as an identity claim |

## Pairwise findings

| Pair | Result | Core reason |
|---|---|---|
| Christian returning Jesus / Islamic returning Jesus | I-5 | Same historical referent; ontology and mission differ |
| Jewish Messiah / Jesus | I-4/I-3 | Christianity explicitly assigns inherited Jewish messianic expectation to Jesus |
| Sunni Mahdi / Twelfth Imam | I-3 generally; I-4 within Twelver doctrine | Same Mahdist tradition family; specific identity is sectarian |
| Antichrist / Dajjal | I-2/I-3 | Strong late-antique genealogical/functional relationship |
| Jewish Messiah / Mahdi | I-1/I-2 | Similar restorer function, no personal identity evidence |
| Saošyant / Jewish Messiah | I-2 | Possible influence, different indigenous role genealogies |
| Saošyant / returning Jesus | I-1/I-2 | Functional parallels, incompatible biographies |
| Saošyant / Maitreya | I-2 at most | Possible later contact; earliest roles differ |
| Maitreya / Kalki | I-1/I-2 | Shared environment, different ontology |
| Kalki / Saošyant | I-1/I-2 | Restoration analogy |
| Mahdi / Maitreya | I-1 | Structural analogy only |
| Mahdi / Jesus | I-0 as simple identity | Dominant Islamic traditions normally distinguish them |

## Main result

Three different phenomena must not be conflated:

1. Same person directly inherited across traditions: strongest case Christian Jesus / Islamic Jesus.
2. Same inherited role assigned to a person: Christian Messiah identification; Twelver Mahdi identification.
3. Analogous future-restorer roles with no identity evidence: Mahdi, Maitreya, Saošyant, Kalki across traditions.

## Restoration grammar

A true order exists → humans depart from it → knowledge/morality/justice decline → ordinary institutions fail → extraordinary agent appears → alignment is restored → better age begins.

The evidence supports a common eschatological grammar more strongly than a claim that all traditions independently predict one identical future individual.
