# WP-013 — Evidence Update Rules

## If all confirmatory tests are null
Update:
- H1/H2/H12 gain relative support;
- H4 is not disproved universally;
- specific tested claims lose support.

## If one lab is positive and others null
Classify:
**unreplicated anomaly / site effect**.
Investigate leakage, analysis, participant selection.

## If multisite anomaly replicates
Promote H9 strongly:
**anomalous information detected, source unresolved.**

Then design source-discrimination experiments.

## If entity-specific information independently replicates
H4 becomes materially stronger only if:
- normal leakage excluded;
- entity identity passes continuity tests;
- alternative anomaly models compared.

## If prospective prophets outperform benchmarks repeatedly
The relevant claimant/method gains evidence.
Do not generalize automatically to every doctrine claimed by that prophet.

## If channelers claiming same entity converge specifically under isolation
Update EID criteria and H4.
Generic spiritual language is insufficient.
