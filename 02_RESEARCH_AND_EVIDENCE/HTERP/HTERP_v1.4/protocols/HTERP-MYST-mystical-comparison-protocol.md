# HTERP-MYST — Mystical Comparison Protocol

## Purpose
Compare cultivated/spontaneous nonordinary religious experiences without presuming one universal mystical state.

## Record separately
1. induction practice
2. duration/training
3. expectation/script
4. sensory conditions
5. physiology
6. agency
7. self-boundary
8. affect
9. cognition/noetic certainty
10. visual/auditory content
11. propositional information
12. memory
13. transformation
14. social validation
15. later interpretation

## Blinding rule
Where source data permit, code the phenomenological description before coding the tradition/theology.

## Control matching
Each case should be compared with the nearest natural control:
- presence/voice → sleep, bereavement, AVH controls
- ecstasy/certainty → neurological/psychedelic controls
- fasting/isolation → metabolic/sensory-deprivation controls
- repetitive prayer/music → absorption/trance controls
- possession → dissociation/role enactment/social cognition controls

## Transcendent-evidence rule
A mystical state does not materially update H3/H4 merely because it is intense or transformative.
Update requires either:
- independently verifiable information/effect; or
- a pattern unexpectedly specific under H0–H2 and independently replicated.
