# HTERP-PRES — Preservation Vector Protocol

## Problem
A single “years after founder” metric misrepresents traditions preserved through radically different media.

## Vector fields
1. **T — temporal interval** to earliest surviving witness
2. **M — medium**: inscription, letter, manuscript copy, oral poetry, ritual performance, archaeology
3. **R — redundancy**: number/independence of transmission channels
4. **S — specialization**: professional scribes, reciters, priests, knowledge holders
5. **V — variation tolerance**: exact wording versus flexible retelling
6. **E — editorial evidence**: low/moderate/high
7. **A — external anchoring**: datable object/place/event
8. **C — continuity evidence**: documented chain versus retrospective claim
9. **X — access restriction**: none/initiatory/lineage/gender/community restricted
10. **L — language continuity**: original language retained, translated, reconstructed

## Rule
Do not collapse the vector to one global score. State which historical questions each preservation system can and cannot answer.
