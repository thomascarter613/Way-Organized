# Corporate Record Book - Permanent Tab Index

| Tab | Contents | Retention class |
|---|---|---|
| 1 | Filed Charter, amendments, Secretary of State acceptance | Permanent |
| 2 | Bylaws, variant schedule, amendments | Permanent |
| 3 | Incorporator actions and organizational meeting/consents | Permanent |
| 4 | Board/member minutes and written consents | Permanent governance record |
| 5 | Director/officer roster, terms, acceptances | Permanent + historical |
| 6 | Founder Covenant and Board Reserved Powers | Permanent while governing + historical |
| 7 | Committee charters, rosters, minutes | Governance retention schedule |
| 8 | Conflict/independence disclosures and related-party records | Long-term; counsel/accountant schedule |
| 9 | EIN, IRS Form 1023/application, determination letters, tax correspondence | Permanent |
| 10 | Tennessee filings, annual reports, solicitation status | Permanent/long-term |
| 11 | Finance: budgets, statements, bank-control records, audits/reviews | Accounting retention schedule |
| 12 | Compensation approvals/comparability files | Long-term/permanent for insiders |
| 13 | Insurance policies/claims | Long-term; claims permanently indexed |
| 14 | Safeguarding governance/training records | Restricted, long-term per counsel/insurer |
| 15 | Complaint/investigation index (case files separately restricted) | Restricted; counsel-approved |
| 16 | Property, leases, major contracts, debt | Life of asset/contract + retention period |
| 17 | Intellectual property, names, domains, publications | Long-term |
| 18 | External integrity reviews and remediation | Permanent governance record |
| 19 | Annual integrity certifications/dashboard | Long-term/permanent summary |
| 20 | Dissolution/merger records if ever applicable | Permanent |

## Restricted files
Safeguarding, personnel, pastoral-care, whistleblower, medical, legal-privilege, and investigation files should not be stored in an unrestricted general board folder merely because the record book contains an index to them.
