## Decision gates intentionally left open

1. **Legal name.** Replace `[[ORGANIZATION_NAME]]` everywhere before filing/adoption.
2. **Statutory-member model.** Tennessee requires the charter to state whether the corporation will or will not have members. Select one v0.2 charter variant before filing.
3. **Initial directors/officers.** Insert actual people only after independence/conflict screening.
4. **Federal classification.** The organization should not assume it qualifies as an IRS "church" merely because it is religious. If it seeks IRS recognition as a church, Form 1023 (not Form 1023-EZ) is the appropriate application route under current IRS instructions. If an established congregation or other church facts do not yet exist, counsel/tax advisers should consider whether to apply initially as another religious public charity classification and revisit church classification later.

## Governing hierarchy

Applicable law / valid court order -> filed charter -> bylaws -> entrenched integrity schedules -> board policies -> SOPs -> forms/guidance. No lower-level document may reduce a higher-level conscience, safeguarding, independence, financial-integrity, complaint, or exit protection.

## Counsel review

This package is designed to make counsel review efficient, not to replace it. Before filing or signing, Tennessee nonprofit counsel should verify the charter, religious-corporation provisions, tax posture, employment/ministry implications, insurance, charitable-solicitation status, and any provision interacting with ecclesiastical-autonomy doctrine.
