# Day-One Implementation Queue

## Before filing / organizational meeting
- [ ] Select statutory-member or nonmember charter variant.
- [ ] Complete Tennessee charter placeholders and obtain counsel review.
- [ ] Identify at least five formation directors, majority independent; recruit to seven within 180 days.
- [ ] Conduct conflict and independence screening before directors vote on insider matters.

## Organizational meeting
- [ ] Adopt bylaws and selected variant schedule.
- [ ] Adopt Participant Bill of Rights and Institutional Integrity Framework.
- [ ] Adopt Founder Covenant; serving founder signs.
- [ ] Adopt Reserved Powers Schedule.
- [ ] Appoint officers and standing committees.
- [ ] Approve bank/signing/payment authority matrix.
- [ ] Adopt conflicts, compensation, finance, safeguarding, complaint, investigation, discipline, exit, pastoral ethics, doctrine/revelation, and external-review policies.
- [ ] Establish corporate record book and document hierarchy register.

## Before accepting public participants / donations
- [ ] Publish rights, complaint channels, safeguarding contact, leadership/board identities, and basic governance explanation.
- [ ] Activate independent complaint channel.
- [ ] Establish bookkeeping, bank reconciliation, restricted-fund tracking, and approval thresholds.
- [ ] Complete initial leader/director conflict disclosures.
- [ ] Approve any founder/executive compensation using disinterested process and comparability data.

## Before serving minors/vulnerable adults
- [ ] Safeguarding lead appointed and independent escalation route active.
- [ ] Required screening/background checks complete.
- [ ] Covered workers trained.
- [ ] Reporting quick card distributed.
- [ ] Two-adult/observable environment, transport, overnight, communications, and media rules active.

## First 90 days
- [ ] Recruit board to full 7-11 structure and achieve >=2/3 independence.
- [ ] Run first speak-up test / anonymous channel test.
- [ ] Run tabletop exercise: complaint against founder/chief executive.
- [ ] Run tabletop exercise: child-safety disclosure.
- [ ] Run tabletop exercise: related-party transaction.
- [ ] Complete first quarterly integrity dashboard.

## First year
- [ ] Independent financial review level set based on resources/risk.
- [ ] Board self-assessment and leadership integrity certifications complete.
- [ ] Publish annual transparency report.
- [ ] Commission first external integrity review no later than 18 months after public launch.
