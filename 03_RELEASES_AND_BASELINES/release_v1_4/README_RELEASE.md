# The Way v1.4 - Pilot Operations Release

Built September 21, 2026.

This release operationalizes the Founding Gathering Circle as a 90-day adult pre-incorporation pilot. It does not create a corporation, recognized House of Prayer, statutory membership body, or tax-exempt status.

## Core files
- Founding Gathering Circle Pilot Operations Manual v1.4
- Founding Gathering Circle Participant Packet v1.4
- Pilot Evidence & Review Tracker v1.4
- source/ pilot session register, quick cards, Markdown sources, structured JSON

## Human gate before recurring public sessions
A genuinely independent complaint/safeguarding contact must be identified and made available to participants.
