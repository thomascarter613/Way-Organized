# Founding Gathering Pilot Launch Checklist v1.1

Before the first public pilot gathering:

- [ ] Publish experimental/pre-incorporation status.
- [ ] Make Companion Handbook / participant rights available.
- [ ] Activate a normal concern contact and a genuinely independent/outside concern route.
- [ ] Confirm venue exits, emergency services, incident contact, and accessibility.
- [ ] Keep pilot adult-only by default; no children’s ministry or unsupervised child programming.
- [ ] State founder role and non-infallibility explicitly.
- [ ] Do not represent a corporation, 501(c)(3), tax-deductible donation program, official House, or clergy system as existing before lawful establishment.
- [ ] Avoid public charitable fundraising before entity/control/status review; document shared-cost arrangements transparently.
- [ ] Prepare anonymous 30/60/90-day feedback instruments.
- [ ] Schedule founder-exit facilitation exercise for week 11.
