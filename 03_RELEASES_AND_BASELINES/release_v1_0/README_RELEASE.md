# The Way v1.0 Founding Synthesis

This release reconciles v0.5-v0.9 into the first coherent public-facing religious baseline.

## Core publications
1. Constitution of the Way v1.0
2. Teaching & Practice Baseline v1.0
3. Companion Handbook v1.0

## Status
Founding synthesis for pilot use, community review, legal/corporate reconciliation, and future amendment. It is not a claim that theology is complete.

## Critical distinction
The Constitution of the Way is a religious constitution. It does not replace the Tennessee nonprofit corporation's charter/bylaws or civil-law fiduciary responsibilities.
