# Releases and Baselines

This directory preserves immutable release/reference snapshots.

## Lineage

- `reference_v0.8/` — historical reference baseline
- `v0.9/` — historical ethical/eschatological release
- `release_v1_0/` — **first coherent public-facing religious/founding synthesis**
- `release_v1_1/` — adoption and organizational-instantiation layer built on v1.0
- `release_v1_2/` — **current execution/filing release**, carrying forward v1.0/v1.1 reference material
- `release_v1_4/` — **current pilot-operations/evidence framework** for the 90-day adult pre-incorporation Founding Gathering Circle
- `release_v1_5/` — **current pilot-curriculum release record**, expanding v1.4 into a 13-week print-and-run curriculum

These releases are function-specific rather than one linear authority ladder: v1.0 remains the founding religious synthesis, v1.2 remains the current filing/execution package, v1.4 remains the pilot operating/evidence framework, and v1.5 is the current curriculum layer built on v1.4.

The v1.5 README states that binary curriculum artifacts remain in the ChatGPT project deliverable; the repository stores the release record and tracked editable-source lineage. Do not describe `release_v1_5/` as a complete in-repo binary package unless those artifacts are later committed.

Historical release contents should normally remain byte-stable. Corrections belong in new releases or explicit errata.
