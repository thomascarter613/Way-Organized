# Releases and Baselines

This directory preserves immutable release/reference snapshots.

## Lineage

- `reference_v0.8/` — historical reference baseline
- `v0.9/` — historical ethical/eschatological release
- `release_v1_0/` — **first coherent public-facing religious/founding synthesis**
- `release_v1_1/` — adoption and organizational-instantiation layer built on v1.0
- `release_v1_2/` — **current execution/filing release**, carrying forward v1.0/v1.1 reference material

v1.2 is the latest execution package; it should not be described as replacing v1.0's religious synthesis unless a future release explicitly changes that baseline.

Historical release contents should normally remain byte-stable. Corrections belong in new releases or explicit errata.
