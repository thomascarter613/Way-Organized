# Historical and Pre-Integration Packages

This area preserves older, flattened, duplicate, predecessor, export, and production-package material for provenance.

Material here is **not current by placement**.

Do not delete duplicates from this area until the corresponding current/canonical source and historical relationship have been verified. Many files intentionally mirror material that later moved into `institution/`, integrity releases, or versioned religious releases.


## Packaged archive shelf

Historical ZIP packages formerly held under `99_UNCLASSIFIED/.archive/` are now classified under:

`archive-packages/`

Subgroups:

- `research-hterp/` — packaged HTERP baselines/work packets
- `religious-source-releases/` — theological, lexicon, community-architecture, and foundational release/source packages
- `organizational-releases/` — packaged v1.1/v1.2 organizational/execution releases
- `institutional-integrity/` — institutional-integrity source and complete-release packages
- `institutional-and-church/` — church/institutional/operations/template/constitutional packages
- `digital-platform/` — packaged application foundations

See `archive-packages/ARCHIVE_PACKAGE_REGISTRY.csv` for the old path, new path, SHA, size, category, and package type of every moved ZIP.

The move is a lifecycle/path reclassification only. The ZIP blobs were reused unchanged.
