# Foundational Witness Selection Dossiers (FWSD)

This directory contains candidate-by-candidate evaluations produced under **EPC-004 — Foundational Witness Selection Protocol**.

These dossiers do **not** constitute canonical admission. They document source-critical evaluation, proposition extraction, ethical and contradiction review, adversarial objections, authority profiles, and provisional procedural status.
