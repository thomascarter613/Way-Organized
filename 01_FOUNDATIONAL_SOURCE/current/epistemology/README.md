# Epistemology, Revelation, and Canon — Current Drafting Home

This directory is the designated **forward drafting home** for future consolidated work on:

- epistemology;
- revelation discernment;
- prophecy;
- authority;
- scripture;
- Library of Witnesses governance;
- foundational-witness status;
- canon formation;
- doctrinal confidence;
- revision and amendment rules.

It begins as a repository-architecture decision, not an adopted theological instrument.

## Why this home

Related rules currently exist in several places:

- foundational source;
- HTERP constructive theology;
- institutional-integrity policy.

Those documents should remain where they are for provenance.

New consolidation work should happen here so that the repository does not create another cross-domain ambiguity.

## Lifecycle

The intended path is:

```text
existing source documents
        ↓
crosswalk
        ↓
consolidated draft here
        ↓
review
        ↓
future foundational release, if approved
        ↓
separate institutional adoption/implementation, if required
```

A document stored here is a **draft/source artifact**.

It does not become:
- binding doctrine;
- institutional policy;
- constitutional law;
- or canon

without the relevant later process.
