# Foundational Source

This domain now has two distinct lifecycle paths.

## Current forward authoring

Use:

`current/`

for new foundational religious/theological source work created after second-pass repository curation, except where an active series was already established under the legacy tree and should remain cohesive.

This clean path exists so future unrelated drafting does not add another generation into the mixed historical source tree.

## Legacy authoring provenance

The existing:

`source/`

tree is preserved in place as **mixed-lifecycle authoring provenance**.

Its internal `00_README.md` describes a v0.8 research/source pack, while the same tree also contains v1.0 synthesis material and v1.2 execution-source artifacts. Do not infer that every file in that folder belongs to one coherent version.

Do not mass-move or rename the legacy tree. Existing release/source references and provenance depend on its paths.

### Active-series exception

Two active series were established under the legacy tree before/during this curation pass:

- `source/epistemology/` — EPC-001 through EPC-004 and related EPC work;

Continue those series together in their established locations unless a dedicated migration moves the whole series and updates references atomically. Do not split a numbered series merely to satisfy the newer directory policy.
