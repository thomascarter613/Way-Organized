# Unclassified

This is the repository's holding area for material that cannot yet be classified safely.

**Current state:** no project artifact is presently stored here; only this README remains.

The historical ZIP packages formerly under `.archive/` were reviewed and moved, byte-for-byte, to:

`../80_HISTORICAL_AND_PREINTEGRATION_PACKAGES/archive-packages/`

Their path migration and SHA values are recorded in:

`../80_HISTORICAL_AND_PREINTEGRATION_PACKAGES/archive-packages/ARCHIVE_PACKAGE_REGISTRY.csv`

Placement here in the future means **preserved pending review**, not rejected, obsolete, or authoritative.

Before moving or deleting a future item:

1. identify its provenance;
2. compare it against repository inventories and current/canonical paths;
3. determine whether a current/canonical/release counterpart exists;
4. record the lifecycle decision in a reviewed change.
