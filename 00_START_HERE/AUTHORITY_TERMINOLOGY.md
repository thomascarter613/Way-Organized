# Authority and Canon Terminology Map

**Status:** repository curation terminology  
**Date:** 2026-09-21  
**Purpose:** Prevent repository terms from being mistaken for stronger theological or institutional claims than the source material supports.

This document does **not** adopt a canon or create doctrine. It defines how repository-maintenance language should be read until a formally adopted authority instrument says otherwise.

## Current terminology

### Library of Witnesses

Use for the broad religious/source collection preserved for study, comparison, historical reconstruction, and theological work.

This term does **not** imply that every included witness is equally authoritative, historically reliable, or doctrinally binding.

### HTERP proto-canon

Use only with the qualifier:

> **HTERP proto-canon / research source-priority architecture**

This refers to HTERP's constructive-theology reading priority.

It does **not** mean:
- closed canon;
- infallible canon;
- formally adopted canon of The Way;
- or material that is automatically binding on participants.

### Foundational witness

Use for a source or corpus judged especially important to identity, historical reconstruction, or constructive theology.

Until formally adopted, the label does not by itself specify:
- infallibility;
- textual inerrancy;
- exclusive authority;
- or institutional legal effect.

### Foundational Witness Corpus

Reserve this phrase for a future explicitly constituted collection if the community adopts such a structure.

Repository curation must not silently create an FWC by moving files into a directory.

### Liturgical source

A text authorized or selected for worship, prayer, recitation, teaching, or communal gathering.

Liturgical use does not automatically imply highest historical or doctrinal authority.

### Doctrinal source priority

A formal ranking governing how competing sources are weighted in theological reasoning.

No repository path currently establishes this merely by placement.

### Binding doctrine

A teaching that the relevant community authority has actually adopted as binding through a defined process.

Research conclusions, draft constitutions, release snapshots, personal revelations, and repository metadata are not binding doctrine merely because they exist.

### Adopted institutional instrument

A governance, policy, constitutional, doctrinal, or operational instrument that has been approved through the applicable institutional process and whose adoption record is preserved.

"Adopted" is an evidence-bearing lifecycle state, not a synonym for "drafted."

### Canonical institutional repository

This phrase refers to:

`04_INSTITUTION_AND_GOVERNANCE/institution/`

It means the controlled repository for current institutional instruments and records.

It does **not** mean that every file in that tree is religious canon.

### Canonical path

In repository curation, "canonical path" means:

> the designated current repository home for a class of artifacts.

It does not mean scriptural canon.

## Current repository posture

The reviewed corpus presently supports this distinction:

```text
Library of Witnesses
        ↓
research/source prioritization
        ↓
foundational-witness proposals
        ↓
constructive theological synthesis
        ↓
formal review/adoption process
        ↓
binding doctrine and/or constituted canon, if adopted
```

The repository must preserve each stage separately.

## Governing rule

When a term could be misunderstood, prefer the longer precise form over the shorter ambiguous form.

For example:

- write **"HTERP proto-canon / research source-priority architecture"**, not simply **"the canon"**;
- write **"canonical institutional repository"**, not **"canonical religious corpus"**;
- write **"released snapshot"**, not **"adopted doctrine"**, unless adoption evidence exists.
