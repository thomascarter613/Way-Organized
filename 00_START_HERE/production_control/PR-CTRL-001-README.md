## Purpose

PR-CTRL-001 is the corpus-wide reconciliation index for the Way / Assembly project. It does not replace the canonical institutional repository controls. Instead, it connects the historical FOUND-series, released religious baselines, current institutional drafts, CH-series production corpus, working research, integrity materials, and archive collections so they can be finalized without accidental supersession or authority drift.

## Core control rule

**Repository placement is not adoption.**

The canonical institution migration note explicitly requires verification of source bytes and constants, identification of competent adopting authority, actual organizational action, entry in ADOPT-001 / the Activation Control Workbook, and preservation of the pre-adoption version before promotion to adopted `1.0.0`.

## Register status vocabulary

- **CLASSIFIED** — located and assigned a lifecycle/authority role.
- **DRAFT_FRAMEWORK** — substantial framework exists but the proper canonical instrument and/or real-world facts are incomplete.
- **RECONCILING** — content exists but conflicts, overlaps, terminology, or authority dependencies remain unresolved.
- **REVIEW_READY** — substantial content exists and can be reviewed once parent authorities/constants are stable.
- **CONTENT_COMPLETE** — content appears structurally complete but this does not imply adoption.
- **PUBLISHED** — immutable release/reference snapshot; publication does not imply institutional adoption.

## Maintenance rule

Every finalization decision must update this register. When PR-XWALK-001 establishes that one artifact supersedes or absorbs another, the predecessor must remain preserved and its relationship recorded rather than deleted.
