## Controlled gates that still require real-world input
1. Final clearable legal/public name.
2. At least two additional natural-person directors; target four additional formation directors.
3. Secretary different from President.
4. Registered/principal office addresses.
5. Final attorney review before Tennessee filing.
6. Good-faith financial projections before Form 1023 filing.

The packet is structured so these values can be inserted without another governance-design pass.
