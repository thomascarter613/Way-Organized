# Assistant-to-Repository Workflow

## Purpose

This repository is the durable working record for the Way project.

Beginning 2026-09-21, substantive ChatGPT work for this project should be preserved in this repository when GitHub access is available.

## Rules

1. Formal deliverables go in the most appropriate existing subsystem rather than in the chat archive.
2. Chat responses are indexed under 90_WORKING_NOTES_AND_SCRIPTS/Chat_Responses/.
3. If a response is itself a formal deliverable, the chat archive may point to the authoritative deliverable instead of duplicating the entire file.
4. Chat-response filenames use a date plus a descriptive kebab-case title.
5. New work must not silently overwrite older baselines or mature subsystem artifacts.
6. When newer work revises an older artifact, preserve provenance and clearly mark version/status.
7. If exact earlier transcript text is unavailable in the active session, archive a clearly labeled reconstruction or summary rather than pretending it is verbatim.
8. Future substantive responses and deliverables should be committed to this repository as part of the working flow whenever the GitHub connector is available.
