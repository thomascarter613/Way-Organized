# Institution and Governance

The primary tree is:

`institution/`

Its own README identifies it as the **Canonical Institutional Repository** and subjects it to REPO-001, REC-ID-001, ORG-CONST-001, and ADOPT-001 controls.

"Canonical institutional repository" identifies the controlled institutional home. It does **not** mean that every draft/template in the tree is already legally operative.

Adoption, filing, officeholder facts, EINs, addresses, financial history, and executed records must remain truthful and separately evidenced.
