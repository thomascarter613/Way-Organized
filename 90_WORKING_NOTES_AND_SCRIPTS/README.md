# Working Notes, Scripts, and Response Archives

This domain contains non-authoritative working material, helper scripts, legacy notes, and assistant-response archives.

Nothing acquires doctrinal, institutional, canonical, or release authority merely by being stored here.

## Structure

### `Chat_Responses/`

Canonical forward archive for substantive Way-project assistant responses.

Use the dated/indexed convention documented in `Chat_Responses/README.md`.

When a response produces an authoritative deliverable elsewhere in the repository, prefer a short archive record linking to that deliverable rather than maintaining two divergent authoritative copies.

### `chat-responses/`

Legacy lowercase response archive preserved for provenance.

It is intentionally **not** case-renamed into `Chat_Responses/`, because historical links and commit history may refer to the existing lowercase paths.

Do not create new responses here.

### `Notes/`

Legacy and exploratory working notes. These may contain useful context, prior decisions, generated content, or superseded thinking.

Treat them as working/provenance material unless an item has been deliberately promoted into a controlled subsystem.

### `scripts/`

Helper and audit scripts used to inspect, organize, validate, or maintain repository material.

Scripts do not create authority over the content they process.

## Forward rule

New substantive responses belong in `Chat_Responses/YYYY-MM-DD/`.

New formal deliverables belong in their authoritative subsystem, with the response archive linking to them.

New exploratory notes may remain under `Notes/` until deliberately integrated.
