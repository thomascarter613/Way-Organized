# v1.5 Print-and-Run Pilot Curriculum

Work Mode continued from v1.4 pilot operations into session-level execution.

Created:
- a 27-page Facilitator Binder
- a 27-page Participant Workbook
- thirteen individual weekly facilitator/participant packets
- editable Markdown source packets
- session and reading registers
- structured curriculum state
- a complete release ZIP and editable source ZIP

The curriculum is intentionally adult-only, pre-incorporation, non-fundraising, and experimental. It preserves the independent complaint-route requirement and does not represent the Gathering Circle as a recognized House of Prayer, corporation, or tax-exempt charity.

Each week contains objectives, readings/witnesses, claim-status cues, a timed agenda, practical exercise, dissent check, participant handout, take-home practice, anonymous feedback, and facilitator after-action review.

The weekly sequence culminates in a founder-exit exercise, complaint/exit tabletop, and evidence-based Day-90 continue / revise / pause / close decision.

QA was completed by rendering and visually inspecting the two master books and every weekly packet; all DOCX accessibility audits returned zero findings and all final PDFs passed preflight.
