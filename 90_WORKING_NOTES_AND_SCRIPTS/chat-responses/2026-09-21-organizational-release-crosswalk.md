# Second-Pass Curation — Organizational Release Crosswalk

**Date:** 2026-09-21  
**Branch:** `curation/repository-second-pass`

Continued repository curation focused on IG-005, the overlap between v1.1/v1.2 organizational releases and the canonical institutional repository.

Key result: the release packages should remain immutable reference snapshots. They should not be copied wholesale into the canonical institution tree. Instead, actual records should enter the institution repository event-by-event when there is real evidence of adoption, execution, filing, acceptance, issuance, or other operative status.

A new crosswalk maps v1.1/v1.2 artifacts to canonical formation, governance, financial, EIN, Form 1023, and Schedule A homes and defines lifecycle states from REFERENCE/TEMPLATE through ACCEPTED/ISSUED and SUPERSEDED.

No substantive release or institutional file was altered.
