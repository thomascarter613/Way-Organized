# Chat Responses

This directory archives substantive assistant responses for the Way project.

## Naming

Use:

YYYY-MM-DD-NNN-descriptive-title.md

where NNN preserves sequence within the date when useful.

## Storage rule

When a response is itself a formal deliverable, the response archive may contain a short transcript record and a relative link to the authoritative deliverable. This avoids maintaining two divergent copies of the same document.

Operational progress updates and tool chatter are not treated as independent intellectual deliverables unless they contain material findings.

## Exactness

Files labeled transcript are intended to preserve the response body.
Files labeled reconstruction are summaries produced from the conversation state when the earlier exact text was no longer available in the active context.

## Ongoing behavior

Future substantive responses and deliverables for this project should be added here and/or to their authoritative subsystem location whenever repository access is available.
